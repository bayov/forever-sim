        How these numbers were made

        Every preset uses its own talents, rotation, race, consumes and synthetic Phase 1 gear, plus shared raid buffs.

        • Main number: mean of — fights, same seed for every preset.
        • Fight: —s (± —s) vs a level — boss with no creature type and — armor before debuffs.
        • Races: — fights on every race the class can be.
        • Fight lengths: — fights each.
        • Sample fights: the fights closest to the 10th, 50th and 90th percentile, out of the first — seeds.
        • Racial bars: all racials off (base stats), then one racial off at a time. Overlapping racials split the difference, so the parts add up.
        • Target types: only the boss's creature type changes.
