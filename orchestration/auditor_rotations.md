# Auditor: rotations and resources

Audit each Level 60 rotation (ui/<spec>/apls/*.apl.json, the rotopt templates that produced them, and the class sim code they call) and look for DPS left on the table. Don't use rotopt; read the APL logic, then sim with mksettings + wowsimcli and read debug combat logs (a few iterations, "debug": true) and the result JSON. For each spec: follow a full fight in the log and check every ability is used as intended (priorities, conditions, DoT and debuff refreshes, cooldown and trinket alignment, racials, procs consumed in time, execute phase, channel clipping, swing timer interactions, pet behaviour, totems and buffs maintained); count idle GCDs and wasted time; track the resource (mana, rage, energy, focus) through the fight: when it runs dry, how much regen and potions/runes/Life Tap/Evocation/Mana Tide/Shifting Power give, whether a resource cap wastes regen, and whether the rotation is mana-bound at 120 / 180 / 300 sec in a way that changes what's optimal. Then propose concrete rotation changes (exact APL condition edits) and estimate their gain with a few targeted sims of a hand-edited APL copy in a temp dir (not in the repo). Send each worker its findings with the evidence and the measured gain.
