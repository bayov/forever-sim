# Tasks

Work for forever-sim that needs a person or a local Claude Code session. The daily WoW Forever
update task appends new items under **Open** when it finds work it can't finish on its own,
such as a new client build whose wago.tools data needs to be pulled and processed.

To close an item, tick it and move it to **Done** with the date and the commit or PR that
settled it.

Item format:

```
- [ ] YYYY-MM-DD — <what to do> (<why / source>)
  - <details: build number, wago.tools links, spell or item IDs, sim files, notes.md or audit items>
```
